**Build me a web app called Orbit.**

Orbit is a personal relationship intelligence app — a memory layer for your professional and social life. It is not a CRM. It helps one person remember who they know, how those people connect to each other, and when to reconnect with them.

**Core concept**
The fundamental problem is that human memory is bad at maintaining weak ties. Strong relationships maintain themselves. Orbit exists for everything else: the person you met at an event, the investor who mentioned something useful, the engineer whose context you've lost. The product makes those relationships retrievable and actionable.

**Tech stack**
React frontend, Supabase for database and auth, OpenAI or Claude API for AI extraction, hosted on Vercel. Use Tailwind for styling. Keep it clean and minimal.

**Data model**
People: id, name, company, role, location, how_met, date_met, notes, last_contacted, created_at.
Connections: id, person_a_id, person_b_id, relationship_type, notes.
Interactions: id, person_id, date, summary, raw_note.
Tags: id, person_id, tag (interests, skills, status).

**Core features to build — in this order**

1. Add a person manually: name, company, role, how you met, date, notes, tags.

2. Voice/text dump capture. A text box on the home screen where you type or paste something like "Met Sarah tonight, she's building a healthcare AI startup with Daniel, originally from Chicago, looking for a product person." The app sends this to the Claude API, extracts structured data (name, company, role, location, interests, connections, context, date), and creates or updates the person record automatically. This is the most important feature.

3. People list view. A clean list of everyone in your network with name, company, last contacted date, and a reconnect indicator if it has been more than 30 days.

4. Person detail view. Tap a person and see: when you met, where you met, their interests and skills, their connections to other people in your graph, your interaction history with them, and a notes timeline.

5. Graph visualization. A visual network graph showing people as nodes and relationships as edges. Clicking a node opens the person detail view. Use a library like D3 or React Force Graph.

6. Reconnect prompts. A section on the home screen that surfaces people you haven't spoken to in 30+ days, with the last interaction context shown so you know what to say.

7. Search. A search bar that queries across names, companies, tags, and notes. Later: natural language search like "who do I know that understands fundraising."

**AI extraction prompt to use**
When the user submits a text dump, send this to the Claude API:

"Extract structured information from the following note about a person the user met. Return only JSON with these fields: name, company, role, location, interests (array), connected_to (array of names mentioned), context (how/where they met), date (if mentioned, otherwise today), status (any goals or things they mentioned looking for). Note: [USER INPUT]"

Parse the JSON response and use it to create the person record.

**Design principles**
Clean, minimal, dark or light mode. The home screen has three sections: capture box at the top, reconnect prompts in the middle, recent people at the bottom. No clutter. Every interaction should take under 30 seconds.

**CLAUDE.md spec**
Create a CLAUDE.md file in the root with the following:
- Purpose: personal relationship intelligence app
- Stack: React, Supabase, Claude API, Vercel, Tailwind
- Core principle: capture must be frictionless, under 30 seconds per person
- Do not add features not listed in this spec without asking
- All AI extraction goes through the Claude API using the prompt defined in the spec
- Keep the UI minimal, no unnecessary UI elements

**What not to build yet**
No mobile app. No team features. No calendar integration. No email sync. No relationship scoring algorithm. Build the MVP only.

**Success criteria**
A single user can add a person in under 30 seconds via the text dump, see their full network as a graph, and get prompted to reconnect with people they haven't spoken to recently.
