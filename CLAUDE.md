# Orbit

## Purpose
Orbit is a personal relationship intelligence app.

## Stack
React, PostgreSQL, Claude API via Replit AI Integrations, and Tailwind.

## Core principle
Capture must be frictionless: under 30 seconds per person.

## Guardrails
- Do not add features beyond the product specification without asking.
- All AI extraction goes through the Claude API using the prompt defined in the build specification.
- Keep the UI minimal with no unnecessary UI elements.
